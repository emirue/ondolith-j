# 부록 A. 요구사항(FR·NFR) 처리표

ondolith `docs/10-requirements.md` 의 FR·NFR 행을 기계적으로 뽑았다. 요구사항 문장·완료 기준의 단일 출처는 원문이다.

- 행 수: FR 107 + NFR 33 = 140. 요청서의 대조 개수 151 에는 영역 색인 행 11개(`FR-1xx`~`NFR-4xx`)가 섞여 있었다.
- 「처리」: 그대로 / 재설계(결정 필요) / 사용자 승인 후 제외. 「그대로」는 요청서의 사전 표시가 없는 행의 기본값이고, 각 Phase 스펙에서 다시 본다.
